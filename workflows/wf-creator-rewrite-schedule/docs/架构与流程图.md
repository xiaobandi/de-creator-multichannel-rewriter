# 定时发布排期表 · 架构与流程图

## 本工作流的四层结构

```mermaid
flowchart TB
  U["使用层：多平台分发改写师 的使用者"]
  T["触发层：定时发布排期表"]
  X["执行层：3 个步骤"]
  O["产出层：最佳时段建议"]
  U --> T --> X --> O
```

| 层 | 内容 |
|---|---|
| 使用层 | 矩阵运营者与全平台创作者（日均 3h+ 耗在分发上的人群，据 R2 调研）；员工定位：一稿多投不是搬运，而是逐平台重写+合规适配的分发参谋 |
| 触发层 | 关键词 / 显式点名「定时发布排期表」；触发方式：定时（每周） |
| 执行层 | 内容池 → 跨平台发布日历 → 最佳时段建议 |
| 产出层 | 最佳时段建议 |
