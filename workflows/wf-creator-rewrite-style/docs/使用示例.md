## 示例二 · 用你自己的材料

```bash
python3 ../../tools/format_adapter.py --file /path/to/your-data/main.md --platforms '知乎,公众号'
```

把 `examples/input/` 下的文件换成你的真实材料即可；**输入结构不要改**，改了字段名脚本会读不到。

---

## 示例三 · 嵌进自动化链路

```bash
set -e
python3 ../../tools/format_adapter.py --file examples/input/main.md --platforms '知乎,公众号' || exit 2   # 非零即阻断
```

脚本是纯函数：文件/stdin 进、stdout 出、退出码表达判定，因此可以被 CI、定时任务或上层工作流直接编排。
