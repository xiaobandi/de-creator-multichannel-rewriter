# 使用示例

技能：**合规扫描**（`wf-creator-rewrite-compliance`）

> ⚠️ **本技能的真实效果示例尚未补齐**：以下仅为输入 / 输出契约（**不构成效果证据**）与平台兼容性验证结果。发布前须补至少 3 组「真实输入 → 实际产出」。

---

## 示例一 · 标准用法（真实运行）

```bash
python3 ../../tools/compliance_scan.py --file examples/input/post.txt --platform 小红书
```

**真实输出**：

```console
目标平台：小红书　词表版本：2026.09-baseline
结论：阻断
  - 平台引流 命中 1 处
  - AI 味评分 100，建议改写
AI 味评分：100/100
命中总数：1
  [平台引流] 加我微信
→ 命中高危，不得直接对外发布；逐条替换后重扫。
```

> 医疗功效承诺 + 站外导流被同时命中，给出分级与安全改写方向

> **注意**：医疗、金融、教育三类词的判定阈值最严，**宁可保守**。

---

## 示例二 · 用你自己的材料

```bash
python3 ../../tools/compliance_scan.py --file /path/to/your-data/post.txt --platform 小红书
```

把 `examples/input/` 下的文件换成你的真实材料即可；**输入结构不要改**，改了字段名脚本会读不到。

---

## 示例三 · 嵌进自动化链路

```bash
set -e
python3 ../../tools/compliance_scan.py --file examples/input/post.txt --platform 小红书 || exit 2   # 非零即阻断
```

脚本是纯函数：文件/stdin 进、stdout 出、退出码表达判定，因此可以被 CI、定时任务或上层工作流直接编排。
