# 03 · 场景与价值

## 谁在用

矩阵运营者与全平台创作者（日均 3h+ 耗在分发上的人群，据 R2 调研）

## 三个典型场景

### 场景 A：一稿多投改写
- **触发**：人工（成稿后）
- **之前**：人工从头做一遍，每次口径不一、结果不可比
- **之后**：原稿→抖音文案/小红书笔记/公众号图文/B 站简介逐平台重写
- **收益**：分发 1-3h→30min，月省约 30-60h×¥30≈¥900-1800 vs ¥20-50

### 场景 B：平台合规适配
- **触发**：事件（WF1 后自动）
- **之后**：字数/话题/标签/敏感词逐平台校验→修正
- **收益**：规避因格式/敏感词导致的限流返工

### 场景 C：定时发布排期表
- **触发**：定时（每周）
- **之后**：内容池→跨平台发布日历→最佳时段建议
- **收益**：排期混乱与撞车归零

## 价值构成

| 维度 | 说明 |
|---|---|
| 省时间 | 月省 30-60h 折 ¥900-1800，即便捆绑定价 ROI 仍 >10 倍 |
| 提一致性 | 同一能力固化成技能，口径不再因人而异 |
| 降风险 | 业务红线写死在提示词里，越界即停 |
| 可审计 | 每个数字可回指输入，产出可追溯 |

## 与人工的边界

本员工**不替代决策**。它负责把重复劳动做成清单与初稿，
把决策点（要不要发、要不要改价、要不要道歉）留给人。
